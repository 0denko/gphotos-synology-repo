Google Photos Migrator — package source

This is an unofficial, self-hosted Synology DSM package source for Google Photos Migrator, an all-in-one native DSM 7 app for unattended Google Photos → Synology Photos migration (no Docker or YAML required). The catalog files live here; the .spk packages themselves are downloaded by Package Center directly from the project's GitHub Releases.

Add this source in Package Center

  1. Open Package Center → Settings → Package Sources → Add.
  2. Name: GPhotos Migrator
  3. Location: https://0denko.github.io/gphotos-synology-repo/packages.json
  4. Click OK, then find Google Photos Migrator under the Community section and install it.

Requirements: DSM 7.0 or later, Intel/AMD 64-bit or ARM 64-bit Synology NAS. DSM will show a third-party publisher warning during installation — that is expected for every community package on DSM 7.

If the package does not appear (or the wrong build is offered)

Use the catalog that matches your NAS CPU instead. It contains a single build, so there is nothing to mismatch:

  • Intel / AMD 64-bit models: https://0denko.github.io/gphotos-synology-repo/packages-x86_64.json
  • ARM 64-bit models (aarch64, e.g. DS223, DS423, DS124): https://0denko.github.io/gphotos-synology-repo/packages-arm64.json

Direct downloads

  • gphotos-migrator-dsm7-x86_64.spk (v1.2.0-0001, Intel/AMD)
  • gphotos-migrator-dsm7-arm64.spk (v1.2.0-0001, ARM)
